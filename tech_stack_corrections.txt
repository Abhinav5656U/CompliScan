# Problem Statement: SIH26034
**Title:** Software System to check compliance of Packaged Commodities under Legal Metrology (Packaged Commodities) Rules, 2011
**Sponsoring Ministry:** Ministry of Consumer Affairs, Food & Public Distribution
**Objective:** To develop a system that checks the compliance of packaged commodities with legal metrology rules by scanning products, images, and labels.

# Solution Developed (MeteroLens) - USPs
We have developed a comprehensive, full-stack, hybrid AI-powered platform called **MeteroLens**. 

Key Unique Selling Propositions (USPs) and capabilities include:
1. **Intelligent Data Extraction (Multimodal & CV):** Utilizes Gemini 2.5 Flash and PaddleOCR (Multilingual) to perform OCR and extract structured information (MRP, Manufacturer details, Net Weight, Dates, etc.) directly from uploaded product packaging images.
2. **Dedicated Object Detection & Dimension Calibration (Computer Vision):** Uses custom YOLOv8 object detection combined with OpenCV to accurately detect bounding boxes of mandatory declarations and precisely calculate physical font heights, ensuring strict adherence to dimensional requirements of Legal Metrology Rules.
3. **Automated Image Stitching:** Handles multiple angles of product packaging by seamlessly stitching uploaded images into a single panoramic view before sending it to the AI pipeline.
4. **Hybrid Compliance Rule Engine:** Validates extracted data against Legal Metrology packaging rules using a mix of deterministic checks (Regex, font-height bounding) and a Semantic LLM Judge (Groq LLaMA 3) for ambiguous claims.
5. **Citizen Crowdsourcing with GPS Tracking:** A dedicated public reporting portal for consumers that automatically captures GPS locations (Latitude/Longitude) and flags non-compliant uploads into a prioritized "Risk Queue" on the inspector's dashboard.
6. **Interactive Multilingual AI Assistant & Civic Tech Routing:** An embedded conversational AI that explains rule violations, automatically drafts formal complaints, and routes them (along with Section 65B PDF evidence) directly to the relevant State Controller or Nodal Officer via email.
7. **Bilingual Consistency Checker:** An AI-powered pipeline to cross-check English and Hindi (Devanagari) declarations on the packaging to ensure semantic consistency and prevent mistranslation.
8. **Evidence Integrity & Legal Reporting (Section 65B(4) / Section 63 BSA):** Secures captured image evidence using SHA-256 cryptographic hashing at capture time to ensure non-repudiation. Automatically generates a court-admissible PDF compliance report using ReportLab.
9. **E-commerce Mismatch Detection:** Logic to cross-check physical packaging details against provided e-commerce listing URLs to detect discrepancies.
10. **Role-Based Dashboard Analytics:** A React-based web dashboard featuring trend graphs, compliance ratios, and geographic mapping to monitor metrics across different jurisdictions.
11. **GTIN/Barcode Risk Scoring:** A historical analytics engine that tracks compliance failures by product GTIN (barcode) and automatically assigns a Risk Tier (High/Medium/Low) based on past violations.

# Corrected Technology Stack for MeteroLens (Actual Implementation)

1. **Capture App & Frontend (User Interface)**
- Core Framework: React.js (v18) (Responsive Web App, no React Native)
- Styling: Tailwind CSS
- Dashboard Analytics: Recharts (for trend graphs)
- Map Visualization: react-simple-maps (for geographic plotting of scans)
- Web Scanner: html5-qrcode (for browser-based QR/Barcode scanning)
- Citizen Reporting: HTML5 Geolocation API (silently captures coordinates)

2. **Backend Framework & Authentication**
- Core Framework: Flask (v3.0.3, Python) with modular Flask Blueprints
- Authentication: JWT-based Role Authentication (Flask-JWT-Extended)
- Password Hashing: bcrypt
- Serialization: Marshmallow
- Rate Limiting & Security: Flask-Limiter and Flask-Talisman

3. **Database & Storage**
- Relational Database: PostgreSQL (via psycopg2-binary) managed with Flask-SQLAlchemy and Flask-Migrate
- In-Memory Data Store / Caching: Redis
- Image Evidence Storage: Local File System (`UPLOAD_FOLDER`) + Cloudinary API (No MinIO/S3 used)

4. **AI Label Detection, OCR, & Object Detection (Hybrid Pipeline)**
- Primary AI Engine (Vision + NLP): Gemini 2.5 Flash (via google-generativeai). Handles multimodal label text extraction (OCR) and structured JSON field mapping simultaneously.
- Fallback OCR Engine: PaddleOCR (Multilingual English + Hindi) 
- Object Detection: YOLOv8 (via ultralytics) for precise geometrical validation of the label and bounding boxes.
- Image Pre-processing: OpenCV (cv2) + Pillow for denoising, contrast enhancement, contour analysis, and automated image stitching.

5. **Compliance Rule Engine (Hybrid Deterministic + LLM)**
- Deterministic Validation: Python-based script (`validate_compliance`) executing Regex pattern matching and physical font-height bounds checking against versioned JSON rules.
- LLM Judge (Semantic Verification): Groq API (llama3-8b-8192) evaluates ambiguous rules semantically.
- Bilingual/Script Compliance Detector: Groq API (llama-3.3-70b-versatile) cross-checks English vs. Hindi (Devanagari) to detect mistranslations and inconsistencies.

6. **Product Identity & Cross-Check**
- Validation Service: Web scraping simulation / Mock matching service in `mismatch_service.py`.

7. **Reporting & Evidence Non-Repudiation**
- PDF Generation: ReportLab (Python) for automated compliance certificate generation (Section 65B(4) / Section 63 BSA).
- Evidence Integrity: SHA-256 Cryptographic Hashing applied to image evidence at the time of capture.

8. **Civic Tech & Multilingual Assistant**
- Email Routing & Escalation: Automated drafting and emailing capabilities triggered from the frontend AI Chatbot.
- Multilingual Translation: Supports user interaction and complaint generation in multiple local languages.

# Future Roadmap & Planned Capabilities

- **"Dark Patterns" in Packaging Detection:** Train models to detect deceptive packaging practices that technically follow the rules but mislead consumers (e.g., hiding the MRP under folds, using text colors that intentionally blend with the background, or obscured "shrinkflation" metric changes).
- **Counterfeit & Phantom Manufacturer Detection:** Integrate deep cross-referencing to check if the manufacturer address actually exists using mapping APIs, and verify the GS1 GTIN/Barcode to catch unregistered or counterfeit products alongside standard compliance failures.
